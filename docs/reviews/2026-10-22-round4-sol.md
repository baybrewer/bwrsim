## New findings

R1 is newly enabled below 100 C by round 4. R2 and R3 are the explicitly acknowledged remaining modeling defects, verified rather than claimed as newly introduced. All are accepted-domain boundary defects; the isolated fixtures do not establish ordinary operator-command reachability.

## R1 - IC lag now condenses cold steam into a hotter pool

- **severity:** medium
- **area:** physics
- **file:line:** crates/bwr-core/src/sim.rs:450
- **wrong:** The new vapor-availability gate enables the existing unconstrained duty lag in `ic.rs:158` below 100 C. A consistent sealed, gas-free 90 C vessel with open trains, 100 C pools, 500 kg stored condensate and 5 MW preceding duty per train accepts a 0.05 s step and transfers 4.9875 MW per train into the hotter pool by condensing 2.185046 kg/s of 90 C steam. No wall-energy node funds that transfer: the steam directly supplies the pool's latent heat. At dt=0.025/0.0125 s the corresponding duty is 4.993750/4.996875 MW, so refinement preserves the uphill transfer. The initial transfer alone decreases reservoir entropy by about 368 W/K per train. Before round 4 this below-100 C steam draw was disabled.
- **consequence:** Passive cooldown can boil a 100 C pool using lower-temperature reactor steam, violating the second law while mass and energy conservation still pass. The new 100 C continuity tests use 40 C pools and miss this limiting condition.
- **fix:** With the current algebraic heat exchanger, require positive primary-to-pool temperature drive before allowing lagged condensing duty. Alternatively introduce an explicit wall temperature/energy store and separately constrain each transfer by its temperature drive. Add equal-temperature and hotter-pool tests under timestep refinement, including a cooldown crossing pool temperature.

## R2 - Accepted liquid main-line flow still uses steam hydraulics

- **severity:** medium
- **area:** physics
- **file:line:** crates/bwr-core/src/bop.rs:87
- **wrong:** Water-solid discharge is now correctly deprived of steam work, but line resistance and the valve law at :91 still use the same steam calibration for liquid. The accepted 200 C liquid fixture passes 242.481409 kg/s through those equations. At the calibration state, steam density is 37.696617 kg/m3 versus 864.667500 kg/m3 for 200 C liquid, a factor of 22.94. At equal mass flow and geometry, the leading Darcy pressure-loss dependence is inverse density, so retaining the steam coefficient cannot describe the liquid path. The new pressure test only verifies these same steam equations.
- **consequence:** Flooded-vessel drain rate, chest pressure, level recovery and pressure/isolation response remain unqualified even though turbine work and first-law bookkeeping are fixed.
- **fix:** Pass inlet phase and density into the hydraulic solve, use phase-appropriate line and valve relations with a defined flashing transition, and add an independent liquid hydraulic limiting check. If that path is outside scope, reject/isolate it transactionally rather than accepting steam-calibrated liquid discharge.

## R3 - Cold pressure overrides still decouple core boiling and discharge from mechanical pressure

- **severity:** medium
- **area:** physics
- **file:line:** crates/bwr-core/src/vessel.rs:801
- **wrong:** `eos.subcooled` means T<100 C rather than low mechanical pressure, yet core_sat substitutes atmospheric pressure. An EOS-consistent sealed 90 C, 180000 kg vessel with 100 kg trapped air has total pressure=229956.460 Pa and IF97 boiling temperature=124.681367 C. At inlet h=376968.4 J/kg, core flow=500 kg/s and heat=30 MW, the current core model produces 22.7099% average void and 0.00796676 exit quality; using total pressure with the same axial model gives exactly zero for both. The same shortcut at `sim.rs:440` and `vessel.rs:686` suppresses main-line discharge: an accepted cold, water-solid 40 C fixture at 4.562267 MPa with open MSIVs and TCV reports zero flow and atmospheric chest pressure.
- **consequence:** Cold gas-bearing heatup can create premature void feedback, while a cold hydraulically pressurized vessel cannot discharge through an open line. The browser now uses total core pressure, increasing disagreement with the engine in this range.
- **fix:** Base core boiling on total mechanical pressure throughout the supported EOS domain. Remove temperature-only main-line pressure and flow suppression; select liquid/vapor ports from phase and available inventory. Add sealed cold gas and cold compressed-liquid checks plus a pressure/temperature sweep across 100 C, or explicitly reject these unsupported states.
